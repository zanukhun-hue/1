# AE Plugins Vault SSR

Проект получил серверный режим на Node.js и Express.

## Локальный запуск

```bash
npm install
npm start
```

Адрес после запуска:

```text
http://localhost:3000
```

## Основные изменения

- Страницы собираются через `server.js`.
- Каталог и карточки плагинов отрисовываются на сервере.
- Кнопки скачивания используют маршрут `/download/:id`.
- Повторяющиеся блоки шапки, футера и HTML-обвязки вынесены в общие функции.
- В браузер подключается небольшой файл `client.js` для темы, избранного, меню и фильтров.

## Хостинг

Для такого варианта нужен хостинг с Node.js: Render, Railway, Vercel Serverless/Node, VPS или аналог. GitHub Pages запускает только статические файлы и серверный SSR не выполнит.
