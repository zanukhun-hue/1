# Null—Object AE / Living Collection

Редизайн существующего сайта по визуальному направлению Tistols: чёрная сцена, крупная типографика, контурный персонаж и движение элементов при прокрутке.

## Запуск

```sh
npm ci
npm start
```

Сайт: http://localhost:3000. Переменная `PORT` позволяет выбрать другой порт. Существующие переменные окружения Render, Telegram и базы данных используются как прежде. Для визуального локального просмотра они не обязательны.

## Реализация

- `redesign.js` — новая главная, общая шапка, меню и подвал. Коллекция получает названия, ссылки и изображения из существующих данных проекта.
- `assets/experience.css` и `assets/experience.js` — оформление, жидкое появление заголовков, сворачивающееся меню, взгляд и движение крупных персонажей, объёмный знак Ae.
- `assets/scene-motion.*` — собственный SVG-персонаж, вступительная сценка с демо-окном, переходы между разделителями и упругие SVG-линии.
- `assets/orbit-gallery.*` — 24 настоящие обложки на CSS 3D-плоскостях: куб, переход в сферу, вращение, управление указателем и клавиатурой. Все обложки ведут на страницы плагинов.
- `assets/interior.css` — общий стиль каталога, карточек, пресетов, наборов, рецептов, инструкций и диалогов.

Новые эффекты используют SVG/CSS/JavaScript без дополнительных клиентских библиотек, видеофонов и скачиваемых 3D-моделей. Анимации учитывают `prefers-reduced-motion`, видимость вкладки и мобильный экран. Интерфейс выполнен в единой тёмной теме. Старый декоративный паук отключён.

Каталог, фильтры, избранное, корзина, страницы плагинов, адреса скачивания и магазин пресетов используют существующую логику. На localhost не отправляется аналитика посещений.

## Проверено

- Синтаксис изменённых JS-файлов; `git diff --check`.
- HTTP 200 для главной, каталога, плагина Deep Glow v2, галереи, пресетов, наборов, рецептов, установки, FAQ и контактов.
- В браузере: поиск Twixtor, добавление в избранное и обратно, добавление/удаление из корзины, панель фильтров, меню, сцены главной; ошибок JavaScript в проверенном просмотре нет.
- Визуальный просмотр при ширине 390, 1440 и на широком десктопе.

Оплату, выдачу файлов и серверные интеграции на боевом хостинге эта локальная проверка не запускала.
